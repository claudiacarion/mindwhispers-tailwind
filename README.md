# MindWhispers - A voice for your inner world

### Live Site: https://mindwhispers-tailwind.vercel.app/


### A simple random advice generator built with React and Tailwindcss. Users can click to fetch a random piece of advice from Advice Slip JSON API.

---
## ✨ Features  
- Random advice generated from clicking one button
- Different schemes for light mode and dark mode
---
## 🛠️ Tech Stack
- React
- TypeScript
- Tailwindcss
- Deployment on Vercel
---
## 👀 View Locally
git clone https://github.com/claudiacarion/mindwhispers-tailwind 
cd mindwhispers-tailwind 
cd mindspace-mui  
npm install  
npm run dev
